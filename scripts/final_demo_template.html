A Multi-Agent LLM Framework for Explainable Algorithmic Trading on NSE-Listed Equities

How a decision is made

Four agents each give a stance from −1 (bearish) to +1 (bullish) with a confidence, or abstain when they have no evidence. A trader combines them, and a rule-based risk manager has the final say on position size.

1 · DataAdjusted prices, news headlines and annual reports, each visible only from the date it was public.
2 · Four agentsTechnical (LSTM with attention), sentiment (LLM on headlines), regime (trend and volatility), fundamentals.
3 · DebateWhen conviction is low, an LLM scores a bull case against a bear case.
4 · TraderConfidence-weighted average of the stances gives one score; positive means buy.
5 · Risk managerDeterministic rules: volatility targeting, 20% cap per stock, 100% cap on the book.

Run it yourself

The project is a Python package with over 350 tests. These commands run the test suite and the live pipeline on today's prices.

cd nse_agents
.venv/bin/python -m pytest tests/ -q
.venv/bin/python scripts/run_live_signal.py --backend local
streamlit run scripts/dashboard.py
